# claude-mod-heads-up

A second check that flags what you might miss after longer turns. Switched on per chat and live at once. One Sonnet call per longer turn while on; off at every chat start. Alternative to the built-in You Should Know. Its switch is drawn by claude-mod-mod-bar.

## Install

```bash
claude plugin marketplace add smhasan-yad/claude-mod-heads-up
claude plugin install heads-up@claude-mod-heads-up
```

A new chat or /reload-plugins picks it up. Written for the Windows desktop app and terminal (Claude Code mods API); not tested elsewhere.
